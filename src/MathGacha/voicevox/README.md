# 確率と統計 #1（ガチャ回）VOICEVOX 用

- 声：もち子さん（ノーマル）
- readings.txt：最初に貼った版（89行）。実際の収録はヒデキさんが文を分けて102行に
- MathGacha.vvproj：収録したプロジェクト（102行、もち子さん、全行 話速1.1・抑揚1.2。03-02と04-07の設定もれは修正・再書き出し済み（2026-11-21）。修正前は MathGacha_before-fix.vvproj）
- readings_with_ids.tsv：収録版102行の 番号／行ID／読み／字幕（UTF-8 BOM付き）。旧89行版は readings_with_ids_v1_89lines.tsv
- 音声：voice/MathGacha/{行ID}.wav（102本）。差し替え前の旧音声は voice/MathGacha/_to_delete/（消してOK）
- 読みの列は数字・間違えやすい漢字をひらがなに直してある（余事象＝よじしょう、誤謬＝ごびゅう、表＝おもて など）。字幕の列は元の表記
- 07章の「……」（100連の結果を待つ間）はセリフ無し。動画側で無音の間を入れる
- 思い出しクイズ：06-03 と 06-08（問い）のあとに、動画側で2〜3秒の間を入れる

## 設定（たたき台）
- 話速 1.10 から試す（ミタマ回は1.15）。抑揚・音高はまず初期値で聞いて決める
- 開始・終了の無音 0.1秒
- 決まったら このフォルダに MathGacha.vvproj で保存
- 書き出したら voice/MathGacha/ に移して、番号を行ID（00-01_…）に付け替える
