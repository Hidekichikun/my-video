# 名古屋のVR体験：Horizon of Khufu

## 特定結果

名古屋・栄のスカイル10階「IMMERSIVE JOURNEY 名古屋」で開催されている **Horizon of Khufu（ホライゾン・オブ・クフ）**。2026年1月23日開業、体験本編は約45分。広い空間を実際に歩くフリーローム型VRで、他の参加者もアバターとして認識できる。

- 公式案内: https://immersivejourney.jp/khufu.html
- 会場案内: https://skyle.jp/informations/4085.html
- 制作元Excurio: https://www.excurio.com/en/horizon-of-khufu/

## 体験する主な場面（ネタバレを含む）

1. 現代のギザ台地で、ガイドのモナと大ピラミッドへ向かう。
2. 通常の観光では入れない区画を含め、王妃の間、大回廊、王の間などを巡る。
3. ピラミッド上空・頂上付近からギザ台地と周囲のマスタバ群を見る。
4. 猫の姿で現れる女神バステトに導かれ、約4500年前へ移る。
5. ナイルを船で進み、防腐処置、クフ王の葬送行列・葬儀を目撃する。
6. クフ王の遺体がピラミッドへ納められる物語を体験する。

制作元によれば、ハーバード大学のエジプト学者ピーター・デア・マニュエリアンとGiza Projectの協力を受け、18か月かけて制作された。建築形状やギザの地形は研究資料を基にしている。一方、ガイド、バステトとの遭遇、時間旅行、儀式の細部は物語としての再構成である。

## 史実と演出を見分ける

| VRで見るもの | 史実性 | 見方 |
| --- | --- | --- |
| 大ピラミッドの通路・部屋 | 高い | 現存構造と測量資料を基にした再現。ただし照明・移動方法は演出 |
| 王妃の間 | 部屋は実在、名称は近代の通称 | 王妃が葬られた証拠はない。用途不明 |
| 王の間と石棺 | 実在 | クフの墓室とするのが通説だが、クフの遺体は発見されていない |
| 頂上からの眺め | 仮想だから可能 | 現在は登頂禁止。完成時は白い化粧石で覆われ、今とは外観が違った |
| ナイルの水路と船 | 強い考古学的裏付け | 当時、ギザ近くまでナイルの支流・港湾が延びていた |
| クフ王の防腐処置 | 一般的な王の葬送知識からの復元 | クフ本人のミイラ・葬儀記録はなく、細部は推定 |
| 防腐処置をピラミッド内で行うように見える場面 | 演出に注意 | 長期間の防腐処置は埋葬前に別の施設で行うのが自然で、王の間で行った証拠はない |
| バステト | 神話的演出 | 実在の信仰対象だが、クフ葬儀に猫姿で現れたという史料ではない |
| 太陽の船 | 船そのものは実在 | 南側船坑から解体された船が出土。ただし実際に航行したか、葬送船か、太陽神話上の船かは議論がある |

## 予習動画で優先する内容

- 内部の位置関係：入口→下降通路→上昇通路→大回廊→王の間／王妃の間。
- 完成当時の外観：白く磨かれたトゥーラ石灰岩、現在より約8.5m高い姿。
- ギザが孤立した砂漠ではなく、港・水路・神殿・町を持つ巨大な儀礼・建設景観だったこと。
- クフ、スネフェル、ジェドエフラー、カフラー、メンカウラーの血縁と継承。
- 労働者は「鎖につながれた異民族奴隷」という映画的イメージでは説明できないこと。
- ミューオンで発見されたBig Voidと北面回廊は実在するが、用途はまだ不明であること。

## 当日に気づくための合言葉

- **Akhet Khufu（アケト・クフ）**＝「クフの地平線」。大ピラミッドの古代名で、作品名の由来。
- **王妃の間は王妃の墓ではない。**
- **ギザは墓だけでなく、港・神殿・都市・墓地が一体になった国家事業の現場。**
- **見えている茶色い段々は芯材。完成時の白い表皮はほぼ失われた。**
