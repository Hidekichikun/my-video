# VR体験で見るポイント

## 入る前に頭へ入れる地図

北面入口 → 下降通路  
下降通路から上へ分岐 → 上昇通路 → 大回廊  
大回廊の途中から水平へ → 王妃の間  
大回廊の最上部 → 控えの間 → 王の間  
王の間の上 → 五層の重力軽減空間  
大回廊のさらに上方 → 2017年検出のBig Void

## 体験を一段深くする観察テーマ

### 身体感覚

狭い通路から高い大回廊へ出た時の圧倒感は、断面図だけでは分からない。王の埋葬へ近づくにつれて空間がどう演出されるかを感じる。

### 音と光

古代の内部に現代照明はない。油灯・松明の弱い光、反響、熱、匂いを想像し、VRの見やすさとの差を意識する。

### 人の流れ

完成後の葬列、神官の祭祀、建設中の作業者は同じ動線だったとは限らない。どの場面が「建設中」「葬儀の日」「完成後の祭祀」なのか分けて見る。
