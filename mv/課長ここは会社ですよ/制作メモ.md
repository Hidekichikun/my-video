## 1. コンセプト

- **スーファミ時代のRPG風ドット絵**（前作は格ゲー風。今回はRPG）
  - 課長＝ドワーフ体型なので、RPGキャラとしてハマる
  - 画面下にRPGのメッセージウィンドウ。歌詞もここに出す（前作と同じ仕組み）
  - ツッコミはRPGのシステムメッセージ風: 「課長は 赤ペンを つかった！」「しかし こうかは なかった…」など（文字は編集で入れる。AIに描かせない）
- 完全2D、スプライトは2〜4コマのカクカク（24fpsで3〜4フレーム止め）
- 曲の途中に **寸劇を1回だけ** はさむ（→ 5.）

## 2. 画風（全プロンプト共通・末尾に付けてある）

```
16-bit pixel art, SNES-era 1990s Japanese RPG event-scene style, strictly 2D, flat shading with only 2-3 tones per color, limited color palette, crisp hard square pixel edges, coarse visible consistent pixel grid, no anti-aliasing, no gradients, no 3D rendering, no realistic lighting, dark outlines, no text, no letters, no numbers, no watermark
```
