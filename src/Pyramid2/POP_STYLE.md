# Codex用：エジプト第2弾 見た目をポップにする修正

- 版：v1（2026-10-18）
- 対象：`src/Pyramid2Full/`（`Pyramid2Full` と章別 `Pyramid2Ch00`〜`08`）

## なぜ直すのか

いまの見た目は、暗い背景・明朝体・金色の線で「高級感」寄り。持ち主の希望は逆で、**ハードルを下げて、内容がスッと頭に入る見た目**にしたい。
お手本は前作のサムネ（太い丸っこいゴシック、白文字＋濃い縁取り＋ピンクの影、黄色・水色の角丸バッジ、ピンクの矢印）。
**動画全体を、このサムネと同じノリにそろえる。**

## 変えないもの

- 字幕の文字、音声、タイミング（`TIMELINE`）、章の構成、使うイラスト、確度の札の5種類と意味
- 解説キャラ（位置・口パク・ポーズ）とBGM
- `src/Pyramid/`、`src/PyramidFull/`、`src/PyramidPrevis/` のファイル（部品はそのまま使うか、`src/Pyramid2Full/` で包む・コピーして直す）

## 1. 色とフォント

`src/Pyramid2Full/pop-theme.ts` を新しく作り、ここから取る。

| 名前 | 値 | 使いどころ |
| --- | --- | --- |
| ink | `#2B2B33` | 縁取り、バッジの枠、影 |
| white | `#FFFFFF` | 文字 |
| yellow | `#FFE14D` | いちばん大事な言葉、まとめ |
| cyan | `#3CC8F0` | 用語の札、章の番号 |
| pink | `#FF4F8B` | 矢印、見出しの影、「注意」 |
| brown | `#9A6A3A` | 「いま」「昔」など時代の札 |
| cream | `#FFF6E0` | 文字カード・図の明るい背景 |
| green | `#47C27A` | ○・正しい |
| red | `#F25C54` | ×・後の時代 |

| 用途 | フォント |
| --- | --- |
| 見出し・札・問い・章タイトル | **Dela Gothic One**（`@remotion/google-fonts/DelaGothicOne`） |
| 字幕・説明の文字 | **M PLUS Rounded 1c**（`@remotion/google-fonts/MPLUSRounded1c`）の 800 |

- **明朝体（Shippori Mincho）は全部やめる。**
- フォントの読み込みはレンダー前に完了させる（前作と同じく通信できる環境で書き出す）。

## 2. 字幕

- 位置は今と同じ下（下端から 64px、最大幅 1600px、最大2行）。
- M PLUS Rounded 1c 800、**52px**、白。縁取り ink 10px（`-webkit-text-stroke` か `paint-order: stroke` で文字の外側に）、その外に ink の影 `0 4px 0`。
- **黒い帯はやめる**（縁取りで読める）。明るすぎる絵の上で読みにくい場面だけ、下 1/4 に薄い黒のグラデーション（上 0 → 下 0.45）を敷く。
- **1文字ずつ浮かび上がる演出はやめる。** 1行まるごと、4フレームで下から 12px 持ち上がって出る。消えるのも 4フレーム。
- 字幕の中の**用語を黄色にする**（文字は変えない、色だけ）。対象：ナイル、マアト、カー、バー、アク、偽扉、セルダブ、供物リスト、供物、口開けの儀式、ヘミウヌ、メレル、ヒエラティック、ヒエログリフ、ヘテプヘレス一世、太陽の船、アケト・クフ、ラー、ホルス、アヌビス、バステト。1行で最初に出てきた1つだけ黄色にする（全部塗るとうるさい）。

## 3. 札（バッジ）

いまの小さな文字ラベルを、サムネの「いま」「4500年前」と同じ形に置きかえる。

- 角丸 22px、枠 ink 6px、影 ink `8px 8px 0`（ぼかし無し）、少し傾ける（-3°〜3°、札ごとに固定）。
- 文字は Dela Gothic One 48〜64px。背景が yellow・cyan・cream のときは ink、brown・pink のときは white。
- 色の使い分け：用語の名前＝cyan、意味の説明（「＝○○」）＝yellow、時代・場所＝brown、注意（「※後の時代」「不明」）＝pink。
- 出方：0.6倍 → 1.08倍 → 1倍のバネ（約10フレーム）。2枚以上は 6フレームずつずらす。
- 「A＝B」の札は、A（cyan）と B（yellow）を **pink の太い矢印 `→`** でつなぐ（サムネの矢印と同じ形：枠 ink 6px）。
  - 例：03-04「カー」→「生命を支える力」、02-05「マアト」→「正しさ・秩序」、06-18「アケト・クフ」→「クフの地平線」
- 注記（「※例は〜」）は pink の小さめのバッジ（36px）で、画面の右上か左上。

## 4. 確度の札（`LabelTag`）

- 5種類と色の意味はそのまま。見た目だけ札と同じ形（角丸・ink の枠・ぼかし無しの影）に包む。
- 頭にアイコンを付けて一目で分かるようにする：確定 ✔／有力 ◎／仮説 ？／証拠なし ✖／再現 ✎。

## 5. 背景と文字カード

- **夜（night）の背景をやめ、cream にする**（03-01、03-16、07-14、08-01、08-12 など、絵の無い場面すべて）。
- cream の背景には、うすい水玉か斜めのストライプ（不透明度 6% 程度）を敷いて、のっぺりさせない。
- 文字だけのカードは白い角丸カード（枠 ink 6px、影 `10px 10px 0`）。見出しは Dela Gothic One。
- 「後の時代の話」のカード（03-16、07-14）は、左上に red のバッジ「後の時代の話」、本文の上に大きな赤い × をハンコのように押す（ポンと押される動き）。
- 中央に出す問い（00-03「なぜ、死後のために？」、03-01、08-07〜08-09 の3つの問い）は、サムネのタイトルと同じ：Dela Gothic One 96〜120px、白文字、ink の縁 12px、pink の影 `8px 8px 0`。

## 6. アイコン（`IconRow`）

- 暗い丸に漢字1文字、をやめる。
- 丸の中は**イラストを丸く切り抜いたもの**にする（直径 220px、枠 ink 8px、影あり）。下に札（yellow）で名前。
  - 00-05〜00-08：`01-nile-fields`／`01-king-gods`／`03-ka-offering`
  - 05-25：`05-hemiunu`／`05-boat-stone`／`05-scribe`／`01-bakery-brewery`／`05-hetepheres-furniture`
  - 他の `IconRow`（02-06、05-16、06-04 など）でイラストが合わないものは、丸の中を色（yellow／cyan／pink の順）にして、短い言葉を Dela Gothic One で大きく入れる。
- 1つずつ「ポン」と弾んで出る。00-08 のように「3つそろって光る」は、3つ同時に少し跳ねる＋白いキラッとした光。

## 7. 章タイトル

- 背景 cream＋水玉。左上に cyan の大きな丸バッジで章の番号（「1」〜「8」）。
- 上に小さく部の名前（pink のバッジ）、下に章の名前を Dela Gothic One 110px、白文字＋ink の縁＋pink の影。
- 文字が下から弾んで入る。長さは今のまま。

## 8. いまどこ？バッジ（新しく追加）

- 01〜08章の本編中、画面の左上（上 40px・左 40px、安全領域の内側に収まる大きさ）に小さなバッジ：「③ 死後」のように番号と部の名前。cyan、Dela Gothic One 30px。
- 章タイトルの間とクレジットでは出さない。解説キャラや札と重なる場面では右上に移す。

## 9. 図（三角形・カー/バー/アク・4枚カード・増水の目盛り・配置図）

- 線は ink 6px、面は yellow／cyan／cream／pink のベタ塗り。グラデーションと細い金色の線はやめる。
- カードは 3章と同じ白い角丸カード。番号は丸バッジ（①②③）。
- 04-17 の4枚カードは、上の札（cyan）＝名前、下の札（yellow）＝役目、の2段にする。

## 10. 進め方

1. まず `pop-theme.ts` と、字幕・札・確度の札・文字カード・章タイトル・アイコンの部品を作る。
2. **先に見本の静止画を6枚だけ出して、持ち主に確認してもらう。** `out/pyramid2-pop-sample/`：
   - 00-03（中央の問い）、00-08（アイコン3つ）、01章タイトル、03-04（カー → 生命を支える力）、03-16（後の時代の話）、05-04（確度の札 証拠なし）
3. OKが出たら全章に反映し、いつもの確認（字幕の一致、安全領域、重なり）を通してから書き出す：`out/pyramid2-full-pop.mp4`（前の `pyramid2-full.mp4` は残す）。
4. README.md の「修正箇所」に今回の変更を追記する。
