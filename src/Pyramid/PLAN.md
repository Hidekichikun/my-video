# ピラミッド予習動画 プラン

## 目的

- 名古屋のVR体験「Horizon of Khufu」に行く前に、見どころと背景を知っておくための自分用の予習動画。
- 歴代の王とピラミッドをたどり、それぞれの特徴を押さえたうえで、**クフの大ピラミッドが他と比べて何が特別なのか**が分かる内容にする。
- VRの中で「あ、これがあれか」と気づける状態をゴールにする。VRを観るときの注意点や案内は動画に入れない（2026-09-25 決定）。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 形式 | Remotion、16:9、1920×1080、30fps |
| 尺 | 本編 約12分（ゆっくりした速さ。プレビズのダイジェストは約2分） |
| 語り | ナレーション音声＋字幕。ナレーション原稿は約3,000字（1分あたり約300字） |
| 音声 | VOICEVOX「暁記ミタマ」。話速1.15、音高0.01、抑揚1.5で1行ごとにwavを書き出す。クレジット `VOICEVOX:暁記ミタマ` |
| 絵柄 | 簡易3D（箱・三角錐・透視投影）＋地図・断面図・年表・比較図。鎌倉プレビズの手法を流用 |
| 音 | 自作の仮SE＋落ち着いたBGM（ナレーションの下で小さく） |

### ナレーションの作り方

1. `script.md` に章ごとのナレーション原稿を書く
2. VOICEVOXで章ごとに音声を書き出す（`public/audio/pyramid/ch00.wav` など）
3. 音声の長さを実測して、各章のSequenceの長さを決める（尺は音声に合わせる）
4. 字幕は原稿を文単位で区切り、音声のタイミングに合わせて表示する

※ 音声の長さは申告値ではなく実測する。システムにffmpegが無いので、Remotion同梱のffmpegを使う。
※ VOICEVOXはキャラクターごとに利用規約とクレジット表記の決まりがある。使う声を決めたら確認する。

## ツタンカーメンについて

ツタンカーメンは**ピラミッドを造っていない**。クフより約1200年後の新王国時代の王で、墓はルクソールの「王家の谷」にある岩をくり抜いた墓。この頃の王はピラミッドをやめていた。

そこで第08章で「なぜピラミッドは造られなくなったのか」の答えとして登場させる。有名な王なので、クフとの対比がよく伝わる。

- クフ：巨大な墓を地上に造り、目立たせる → 早い時期に盗掘された
- ツタンカーメン：谷に隠した墓 → ほぼ荒らされずに1922年に発見された

※ ピラミッドをやめた理由は盗掘対策などが挙げられるが、諸説ある。`10_later-kings.md` で確度を確かめてから原稿にする。

## クフだけの特徴（候補）

| 特徴 | 他の王との違い |
| --- | --- |
| 最大 | 建設当時の高さ約146.5m。エジプトで最も大きいピラミッド |
| 部屋が高い位置にある | 多くのピラミッドは埋葬室が地下か基部にある。クフの王の間は内部の高い位置にある |
| 大回廊 | 高さ約8.5m・長さ約47mの持ち送り天井の通路。同じ規模の例が他にない |
| 重力軽減の間 | 王の間の上に積まれた空間。作業班がクフの名を書いた落書きが残る |
| 建設記録がある | メレルの日誌に、大ピラミッド用の石材を運んだ記録が残る |
| 太陽の船 | ピラミッドの脇から、解体された状態の実物の船が見つかった |
| 七不思議で唯一現存 | 古代世界の七不思議のうち、今も残るのはこれだけ |
| 謎が残る | ミューオン調査で見つかった大空間の用途は分かっていない |

※ 数字と「唯一」「最初」の表現は、`11_khufu-unique.md` で出典を付けて確かめてから使う。

## 見せ方のアイデア

- **断面図アニメーション**：大ピラミッドを縦に切り、通路と部屋を順に光らせる。VR内での位置関係が頭に入る。
- **歴代ピラミッドの並べ比べ**：同じ縮尺で横に並べ、章が進むごとに1基ずつ増やす。第10章で全部を並べて、クフの大きさを見せる。
- **今と当時の切り替え**：今の階段状の表面と、化粧石で覆われた白い姿をワイプで切り替える。
- **年表**：ジェセルからツタンカーメンまで約1300年を1本の線に並べ、日本の縄文時代とも比べる。
- **地図**：サッカラ・ダハシュール・ギザ・ルクソールの位置をナイル沿いに示す。
- **諸説の比較画面**：建設方法やピラミッドをやめた理由は、確度ラベルで色分けして断定しない。
