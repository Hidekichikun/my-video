# 恋する牛丼 MVプラン（ただいま正気を失い中）

作成: 2026-11-12（同日更新: 具材でヒロイン完成・つゆだくメーター・夢オチ決定・主人公は男・ゆげや）
- 音源: my-video/music/恋する牛丼.wav（2:39・158.8秒）
- 歌詞: mv/恋する牛丼/恋する牛丼_歌詞.txt（mp3に埋め込まれていた歌詞を書き出したもの）
- ファイル置き場: my-video/mv/恋する牛丼/

## コンセプト
- **ガチの夜の恋愛アニメの作画で、相手がずっと牛丼**。歌詞は全部ラブソングとして成立してるのに、全部牛丼のこと（湯気の向こうの君＝湯気、扉を開けたら君がいる＝お店、少し濡れたまま＝つゆ、真夜中も灯り＝24時間営業、頬を赤く染めたあの子＝紅しょうが、財布を気にしないで＝安い、月みたいな黄色い瞳＝生卵）
- 見せ方は3段階
  1. **Intro〜Verse1は「君」の正体をかくす**: 湯気・逆光・手元だけ。ふつうの切ない恋愛MVに見せる
  2. **Pre-Chorus「最後に帰るのは君のところ」→サビ頭で扉が開いて、牛丼をヒロイン級の作画でドーン**。ここからはかくさない
  3. **ラスト「……そうだ。牛丼、食べよう。」で急に素に戻り、「つゆだくで！！」で全部ぶっ壊す**
- **丼の上で具材がヒロインの顔になっていく（11/12 Hidekiさん案）**: 真上から見た丼に、曲が進むごとに具材がのって顔ができていく。最後に「黄色い瞳」＝卵の黄身が落ちてヒロイン完成
  - 牛肉＝前髪・髪 → 玉ねぎ＝まゆ・口 → つゆ＝唇のツヤ・ハイライト → 紅しょうが＝ほっぺの赤み → 卵の黄身＝瞳
  - 歌詞そのまま: 「頬を赤く染めたあの子」＝紅しょうがのほっぺ、「月みたいな黄色い瞳を そっと君の上に落としたら」＝黄身の瞳
  - 黄身は1個で**ウインク**（もう片方の目は玉ねぎで閉じた目）で決定（11/12。表情が出るから）
  - 具材をのせるのは「オレ」（自分でトッピングして好きな人を完成させる）
- 作画はふざけない（ガチのエモ）、ツッコミはRemotionの文字でやる＝円周ラブ・恋する数学講義と同じ「絵はガチ、ネタは後のせ」
- **カオス・奇妙さ・グリッチは入れない**（11/12）。笑いは「エモをガチでやる×相手が牛丼」のギャップだけで取る。ヒロイン丼の顔は不気味にならないよう、リアルすぎずアニメ寄りで可愛く
- 舞台: 冬の夜の帰り道 → 24時間営業の牛丼屋（架空のお店）
- 色: 夜の紺／湯気と灯りのオレンジ（君の色）／紅しょうがのピンク（あの子の色）／卵の黄色（ラスサビのキー色）
- 画面: 16:9（1920×1080）。ショート用に9:16

## 注意（実在のお店に似せない）
- お店は架空の「**牛丼 ゆげや**」で決定（11/12）（看板の文字はRemotionで後のせ）。実在チェーンの看板の色・ロゴ・制服・どんぶりのデザインには寄せない
- Bridgeの文字は「**はやくて やすい**」（11/12 Hidekiさん）。歌詞の「やさしくて」の上に「やすい」をドンと重ねるツッコミにする。「はやい、やすい、うまい」の3点セットそのままにはしない

## キャラ
- **オレ（主人公）**: 28歳くらいの会社員の男（11/12決定。歌はいつもの女性ボーカル＝円周ラブと同じで、絵の主人公だけ男）。ネイビーのスーツ、ゆるんだネクタイ、少し寝ぐせの黒髪、首から社員証、くたびれたビジネスリュック。最初は死んだ目、牛丼の前ではガチ恋の顔（男が少女漫画みたいな顔になるのがポイント）
- **君＝牛丼**: 真上から見ると、具材で顔ができていく（上のコンセプト参照）。それ以外のカットは斜めや横から撮って顔は見せず、湯気・つや・光で気持ちを表す
- **あの子＝紅しょうが**: 一瞬だけ「ピンクの髪の女の子のシルエット」に見せて、ピントが合うと紅しょうが（嫉妬→勘違い）→ そのまま君のほっぺになる

- **つゆだくメーター**（右上・恋する数学講義のメーターと同じ位置）: 丼を横から切った断面のアイコンで、つゆの水位が上がっていく
  - 段階: つゆぬき → 並 → つゆ多め → つゆだく → つゆだくだく
  - 動き: サビ1で登場（並）→ 16「もっと もっと」でつゆ多め → 25ラスサビでつゆだく → 28「つゆだくで！！」でつゆが丼からあふれて「つゆだくだく MAX!!」、画面がつゆ色（オレンジ）に染まって終わり
  - 水位はちゃぷちゃぷゆれる。上がるときは「とぽぽ…」っぽく波打つ
- **ツッコミテロップ**: 小さめの明朝・右下で「※牛丼です」をラブっぽい歌詞のところに数回だけ（07はまだ出さない、11以降）
- 歌詞: 前半は明朝で切なく、サビからは丸文字ポップでも可。ラストの「つゆだくで！！」だけ画面いっぱいの極太
- 27の「……そうだ。」の前は0.5秒くらい無音っぽく画面を止める
