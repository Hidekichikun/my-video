# リサーチ計画

## 基本方針：VRから逆算する

この動画の価値は「VRの中で気づけることが増える」ことにある。一般的なピラミッド解説を集めるのではなく、先に **VRで何を見るか** を調べ、そこから「知っておくと得する知識」を逆算する。

```
① VR体験を調べる → ② 知っておきたいことリストを作る → ③ テーマごとに深掘り
→ ④ ファクトチェック → ⑤ 驚きポイントの抽出 → ⑥ 映像素材・参考資料を集める
```

## ① VR体験の中身（最優先）

- 正式名称、会場、体験時間、何人で回るか、ガイド役はいるか
- 巡るルート：上空・外観・内部・建設当時の再現・スフィンクスなど
- 「現在の姿」と「建設当時の姿」のどちらを見せるか（あるいは両方か）
- 調べる先：公式サイト、主催者のプレスリリース、他都市での開催時の体験レポートやSNSの感想
- 特定済み：名古屋・栄「IMMERSIVE JOURNEY 名古屋」の `Horizon of Khufu（ホライゾン・オブ・クフ）`。公式・会場・制作元の三系統で確認。

→ 成果物：`00_vr-event.md`（体験ルートの一覧と、各地点で知っておきたいこと）

## ② 何を調べると良くなるか

| 観点 | 調べること | なぜ効くか |
| --- | --- | --- |
| 当時の姿 | 白い化粧石で覆われていた外観、頂上の冠石（ピラミディオン）、周囲の神殿や参道 | 今の姿と違うので、VRで再現されると驚きどころになる |
| 空間の寸法 | 通路・大回廊・王の間の長さ、高さ、傾斜、石材（石灰岩と花崗岩） | 断面図を正確に作れる。VRで自分の位置が分かる |
| 証拠 | 重力軽減の間に残る作業班の落書き（クフ王の名） | 「クフ王が造った」と言える根拠。宇宙人説への答えになる |
| 人の物語 | 建築家ヘミウヌ、労働者村の暮らし（パン・ビール・医療・墓）、メレルの日誌 | 人物がいると記憶に残る |
| 建設方法 | 石切場、ナイル支流での水運、そりと濡らした砂、傾斜路の諸説 | 「有力」と「仮説」を分けて見せられる |
| 最新の研究 | ミューオン調査（ScanPyramids）で見つかった大空間と北面の通路、ギザ近くにあった旧ナイル支流の研究 | 「まだ分かっていないこと」が好奇心を生む |
| 誤解の訂正 | 奴隷説、宇宙人説、「砂漠の真ん中にある」、スフィンクスの鼻 | 誤解を正す場面は面白く、記憶にも残りやすい |
| 時間の感覚 | 日本の縄文時代と比べる。クレオパトラの時代から見てもすでに約2500年前の遺跡だったこと | 「どれだけ昔か」を実感できる |
| 死生観 | カー／バー、来世、太陽信仰、なぜ四角錐なのか | 「なぜ造ったか」に答えられる |

## ③ 情報源

優先度の高い順：

1. **公的機関**：エジプト観光・考古省
2. **大学・研究プロジェクト**：Digital Giza（ハーバード大学／ボストン美術館のギザ・アーカイブ）、AERA（労働者村の発掘）、ScanPyramids
3. **論文**：大空間の報告（Nature, 2017）、北面の通路の報告（2023）、旧ナイル支流の報告（PNAS, 2022）
4. **日本語の専門家**：河江肖剰氏（名古屋大学。ピラミッド研究者で、一般向けの本・動画もある）
5. **書籍**：マーク・レーナー『The Complete Pyramids』など
6. **一般メディア**：NHK、ナショナルジオグラフィック（入口としてのみ使い、数字は上の情報源で確かめる）

注意：ピラミッドはオカルト系の情報が非常に多い。数字や「新発見」は必ず1〜3の情報源まで遡る。

## ④ ファクトチェックのルール

- 数字・年代は **2つ以上の信頼できる情報源** で確かめる
- 年代は「約」を付け、説によって幅があることを明記する（例：クフ王の治世）
- 各事実に確度ラベルを付ける：`確定` / `有力` / `仮説` / `俗説・否定`
- 高さは「建設当時」と「現在」を区別する

## ⑤ メモの書式（1事実＝1カード）

```md
### 大回廊の寸法
- 内容：長さ約○m、高さ約○m、持ち送り式の天井
- 確度：確定
- 出典：<URL>（2つ目：<URL>）
- 映像化：断面図で光らせる。人の影を並べて高さを見せる
- VRとの関係：内部ルートで通るはず → 天井を見上げるように促す
```

こうしておくと、そのまま字幕原稿（`script.md`）と絵コンテに流し込める。

## ⑥ 最後にまとめるもの

- **驚きポイントTOP10**：導入や章の頭に使う「へぇ」ネタ
- **VRチェックリスト**：体験中に見るものを5〜8項目
- **素材メモ**：断面図・配置図の参考資料、ライセンスを確認した画像（Wikimedia Commons など）。動画のビジュアルは基本的に自作し、資料は正確さの確認に使う
