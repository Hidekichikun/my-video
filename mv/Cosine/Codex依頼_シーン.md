# Cosine 〜私・君＝好きの最大値!?〜 MV用イラスト 生成依頼（Codex）

ただいま正気を失い中のMV「Cosine」で使うイラストを作ってください。
前作「Squared」のアンサーソングです。数学オタクの男子をフった文系の女の子「私」が、ベクトルと内積を知って、最後は彼と「同じ向き」になるギャグ×ちょっと胸キュンのMVです。

## 共通ルール
- サイズ：**横 16:9（1920×1080）**（設定画も16:9）
- 保存先：`public/cosine/`（ファイル名は各カットに書いてあるとおり）
- キャラは参考画像に顔・髪型・服をそろえる
  - 私：`public/squared/ref-girl.png`（肩までの栗色のゆるふわ髪、紺のブレザー、ベージュのVネックベスト、白シャツ、**紺のプリーツスカート**）
  - クラスメイトなどの脇役の女の子は、私とかぶらない髪色（黒髪など）にする
  - オタクくん：`public/squared/ref-boy.png`（黒髪ぼさぼさ、丸メガネ、半袖の白シャツ、青いズボン）
  - 王子：`public/cosine/ref-prince.png`（01 で作ったもの）
  - 01〜03 ができたら、04 以降は `ref-girl-faces.png`・`ref-boy-faces.png` も一緒に参考に渡す
- 絵柄：前作 Squared のイラスト（`public/squared/` の絵）と同じギャグ寄りアニメ絵。太めの線、はっきりした色
- 色：方眼ノートの白と薄い水色の罫線、私＝ピンク、オタクくん＝金、王子＝ラベンダー
- 画面の**下から4分の1はごちゃごちゃさせない**（歌詞をのせるので）
- 文字・数字・数式・ロゴ・透かしは入れない（数式と矢印の一部はあとで動画側でのせる）

### 毎回プロンプトの最後に付ける共通文
```
Keep the characters exactly the same as the reference images (girl: shoulder-length wavy chestnut hair, navy blazer, beige V-neck sweater vest, white shirt, navy blue pleated skirt (never beige); nerd boy: messy black hair, round thin glasses, short-sleeved white school shirt, blue trousers; prince: tall, silky light-brown hair, neat navy blazer). Gag anime style matching the previous Squared illustrations, bold clean line art, bright flat vivid colors. Color motif: white graph-paper notebook with pale blue grid lines, the girl's color is pink, the boy's color is gold, the prince's color is lavender. Horizontal 16:9 composition, keep the bottom quarter uncluttered. No text, no letters, no numbers, no equations, no logo, no watermark.
```
