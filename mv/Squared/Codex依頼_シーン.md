# Squared 〜僕×君＝好きの2乗!?〜 MV用イラスト 生成依頼（Codex）

ただいま正気を失い中のMV「Squared」で使うイラストを、シーン11枚＋サムネ1枚作ってください。
数学オタクの男子「俺」が、隣の席の女の子への恋を全部数式で計算して暴走するギャグMVです。

## 共通ルール

- サイズ：**横 16:9（1920×1080）**
- 保存先：`public/squared/`（ファイル名は各カットに書いてあるとおり）
- キャラは参考画像に顔・髪型・服をそろえる
  - 俺：`public/squared/ref-boy.png`（黒髪ぼさぼさ、丸メガネ、ぶかっとした白シャツ）
  - 君：`public/squared/ref-girl.png`（肩までの栗色の髪、紺のブレザー、文庫本）
- 絵柄：参考画像と同じギャグ寄りアニメ絵。太めの線、はっきりした色。黒板の緑・チョークの白・ピンクと金のアクセント
- 画面の**下から4分の1はごちゃごちゃさせない**（歌詞をのせるので）
- 文字・数字・数式・ロゴ・透かしは入れない（数式はあとで動画側でのせる）

### 毎回プロンプトの最後に付ける共通文

```
Keep the characters exactly the same as the reference images (boy: messy black hair, round thin glasses, oversized white school shirt; girl: shoulder-length chestnut hair, navy blazer school uniform). Gag anime style matching the references, bold clean line art, bright flat vivid colors, chalkboard green, chalk white, pink and gold accents. Horizontal 16:9 composition, keep the bottom quarter uncluttered. No text, no letters, no numbers, no equations, no logo, no watermark.
```
