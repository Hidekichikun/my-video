2. `src/MathGacha/voicevox/readings_with_ids.tsv`（102行：番号／行ID／読み／字幕）を読む。**字幕はこの「字幕」列を使う**（台本の文と少し違う行がある。音声に合っているのはTSV）

   - `src/Pyramid2Full/`（章分け・字幕・解説キャラの口パク・クレジット・書き出しスクリプトの形）
   - `src/Pyramid2/POP_STYLE.md`（ポップ路線の色・フォント・札・字幕のルール）
   - `scripts/measure_pyramid2_audio.cjs` など（音声の長さ計測）
4. 3D用の依存を入れる（Remotion 4.0.379 にそろえる）
   - `npm i @remotion/three@4.0.379 three @react-three/fiber` ＋ `@types/three`（dev）

5. 作る場所：`src/MathGacha/`（データ・台本）、`src/MathGachaFull/`（本編コンポーネント）。`src/Root.tsx` に `MathGachaFull` と章別 `MathGachaCh00`〜`Ch07` を追加

## 3. 守ること

- 前作（Pyramid系など）のファイルは変えない
- ガチャ・ルナちゃんは**架空**。実在ゲームの画面・名前・UIに似せない
- 数字は台本どおり（計算済み）：0.99¹⁰⁰＝0.366（36.6%）、当たる確率63.4%、50%→69回、90%→230回、99%→459回、100人中 約63人当たり／約37人ハズレ
- 3Dの「100人シミュレーション」は**当たり63人・ハズレ37人に固定**して見せる（乱数で毎回変わらないように seed 固定 or 決め打ち）
- 書き出しは別名で。前の版は残す

## 4. 見た目（ポップ路線＋3D）

- **色・フォント・字幕・札は `src/Pyramid2/POP_STYLE.md` と同じルール**（Dela Gothic One／M PLUS Rounded 1c 800、白文字＋ink縁取り、yellow/cyan/pink の札、ぼかし無しの影）
- 背景：クリーム＋うすい水玉。暗い背景は使わない
- **先生はイラスト（2D）、数学のもの（ガチャマシン・カプセル・グラフ・100人の列）は Three.js の3D**
  - 3D側はトゥーン陰影（`MeshToonMaterial`）＋輪郭線（裏面拡大のアウトライン）で、イラストになじませる
  - 3Dの色：カプセルは上半分 slate blue `#6682A3`／下半分 透明っぽい白、当たりは金 `#FFD54A` に光る、ハズレは灰 `#B8B8C0`
  - 先生の足元にうっすら楕円の影
- 左上に「いまどこ？」バッジ（章番号と章名）
- 字幕の用語を黄色に（1行で最初の1つだけ）：1%、99%、余事象、ギャンブラーの誤謬、天井、確率、100連、63%、37%

### 先生（Num1先生）の名前表示
- 表記は「**Num1先生**」、読みは「ナミ」
- 00-02（「数学講師の、ナミです。」）で、名前の札「**Num1（ナミ）先生**」をルビ付きで出す。2回目以降は「Num1先生」

### 口パク・まばたき
- 前作 `Pyramid2Full/Guide.tsx` と同じ考え方：音声の音量（エンベロープ）で mouth-closed / half / open を切り替え。無音は closed
- まばたきは 3〜5秒おきに 3フレーム
- 口パクは「talk 系の立ち絵（neutral/talk/mouth-*）」のときだけ。ほかのポーズ（fired-up・shock 等）は1枚絵のまま、小さく弾む・揺れる動きで「しゃべってる感」を出す

## 6. 手順と完成条件

1. 音声をコピー → 長さを実測（前作の measure スクリプトを参考に `scripts/measure_mathgacha_audio.cjs`）→ `src/MathGacha/data/narration.ts`（行ID・字幕・開始フレーム・長さ・章）を作る。行のあいだは 6フレーム、章のあいだは 20フレーム、クイズ・100連の間は上の指定どおり
2. 口パク用エンベロープを作る（前作 `scripts/pyramid2_guide_envelopes.py` 参考）
3. 共通部品：背景、字幕、札、いまどこバッジ、先生（口パク・まばたき・ポーズ切り替え）、3Dステージ
4. 3Dシーン（ガチャマシン、カプセル100個、ちび100人、積み上がるカプセル、コイン、棒グラフ）を作る
5. 章ごとに組む。**まず 00章と 02章だけ作って、静止画を数枚＋冒頭45秒のプレビューを書き出してヒデキさんに見せる**。OKが出てから全体へ
6. 全体を書き出し：`out/mathgacha-full.mp4`。確認用の静止画・コンタクトシートは `out/mathgacha-check/`

完成条件：
- 102行の字幕がTSVの字幕列と一致、音声とずれない
- 数字（上の3章）が全部正しい
- 字幕・札が画面からはみ出さない、重ならない
- 先生の口パクが無音で閉じている
- 前作のファイルが変わっていない（`git status` で確認）

## 7. 困ったとき

- 3Dが重くて書き出しが遅い → 3Dシーンを章ごとに分け、`<ThreeCanvas>` の解像度・影を軽くする。どうしても無理な場面は2Dの図で代用してよい（ヒデキさんに一言伝える）
- 立ち絵の位置がポーズごとにズレる → 足元の位置で合わせる（各PNGの不透明部分の下端を測って揃える）
- 判断に迷ったら、作る前にヒデキさんに聞く
