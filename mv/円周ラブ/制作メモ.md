# 円周ラブ — 制作データ

原案は `円周ラブ_MVプラン.md`、歌詞は `円周ラブ_歌詞.txt`、キャラクターの参照元は `設定画/` の2枚。
主人公の顔、黒ボブ＋ピンクの毛先、白いオフショルダーシャツ、グレーのチェック柄、金のチョーカーは設定画に合わせた。
円の設定画には表情があるが、MVでは原案の「顔なし・中心点・半径」を優先。

## 素材

- `public/enshu-love/03_*.png` ～ `25_*.png`：絵コンテ全23カット。画像内には歌詞・数式を描き込まず、Remotionで重ねる。
- `public/enshu-love/thumb_main.png`：文字を重ねる前のサムネイル。
- `public/enshu-love/short_01.png`、`short_02.png`：縦型専用イラスト。
- `public/enshu-love/prompts.json`：各画像の制作プロンプト。内蔵 image_gen を使用。
- `public/enshu-love/timeline.json`：場面・歌詞・同期モードを含む編集データ。
- `src/EnshuLove/`：独立して起動・書き出しできるRemotionコンポジション。

## プレビュー・書き出し

プロジェクトルートで実行：

```powershell
python scripts/prepare-enshu-love.py
npx remotion studio src/EnshuLove/entry.tsx
npx remotion render src/EnshuLove/entry.tsx EnshuLove output/enshu-love/円周ラブ_MV.mp4 --concurrency=2
npx remotion render src/EnshuLove/entry.tsx EnshuLoveShortChorus output/enshu-love/円周ラブ_short_chorus.mp4 --concurrency=2
npx remotion render src/EnshuLove/entry.tsx EnshuLoveShortBreakdown output/enshu-love/円周ラブ_short_breakdown.mp4 --concurrency=2
npx remotion still src/EnshuLove/entry.tsx EnshuLoveThumbnail output/enshu-love/円周ラブ_thumbnail.png
```

今回の出力をまとめて再生成する場合は `node scripts/render-enshu-love.mjs`。専用の小さな公開フォルダで一度だけバンドルし、全カットの確認PNG、本編、縦型2本、サムネイルを `output/enshu-love/` に出力する。
絵だけを一覧する場合は `public/enshu-love/gallery.html` を開く。

本編は1920×1080、30fps、3分24.76秒の音源を最後まで使用し、「＝」の余韻2秒を追加。映像は約3分26.77秒。縦型は1080×1920。
全体の `src/Root.tsx` にも EnshuLove フォルダを追加済み。

## 歌詞同期

**現時点では仮同期。実音声の歌い出しに合わせた確定同期ではない。**
確定歌詞の全82行をセクションごとの仮尺に配分。場面境界も仮尺。
ブレイクダウンの `(glitch stop)` は画面の動きと歌詞を止めるための演出指示として使用。

`mv/円周ラブ/円周ラブ.lrc` ができたら次を実行：

```powershell
python scripts/prepare-enshu-love.py
```

`[00:43.00]Feel my love!` の形式で1行ずつ記載。歌詞本文は確定TXTと同じ順序・表記にする。
繰り返しのサビもそれぞれ時刻を付ける。セクション見出しは不要。
数式はTXTと同じ3行に分ける。`(glitch stop)` にも時刻を付ける。
スクリプトは空白とマイナス表記の差を吸収して照合し、欠けた行があればエラーにする。
読込後は同期モードが `lrc` になり、歌詞・場面境界・ショートの音源開始位置が更新される。
LRCを置いた後は準備コマンドの実行と再レンダリングが必要。

## 演出

夕方の暖色→夜のピンク・シアン→ブレイクダウンの赤→雨の青→チョーク宇宙の白→朝の白。
カメラの寄り・横移動、チョーク粉、円の描画、英語歌詞の色ずれ、数式の累積表示、3・2・1、マイナスからプラス、停止、ラストの「＝」。
動きはイラストにカメラワークと合成を加えたもの。人物を連続作画したフルアニメーションではない。
